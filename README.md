# brain-state-power-bi-dashboard

Power BI Dashboard including multiple data insights.

Interactive Power BI dashboard analysing brain-wave and vital-sign data of 10 subjects. Used Power Query for cleaning, a star-schema data model and DAX measures to show brain states, dominant waves by hour and subject comparisons.

Key skills used in the project:
Power BI, Power Query, DAX, Data Modelling, Data Cleaning, Data Visualization
